Design and Digital Twin Optimisation of a Hybrid Flow Manufacturing System for a Hydraulic Disc Brake Caliper

Academic project

Manufacturing Systems · Enterprise Dynamics · 2026

Project overview

A hybrid flow manufacturing system was developed for an aluminium-housing hydraulic disc brake caliper assembly. The proposed system combined parallel CNC machining, manual assembly and in-line pressure-decay testing.

The system was designed around a target output of 1,000 units per day and assessed using takt-time analysis, capacity calculations, line balancing, reliability inputs and defect-recirculation logic.

Digital-twin model

The production system was modelled in Enterprise Dynamics. The model included parallel CNC resources, manual assembly, leak testing, rework routing, internal logistics, palletising, an RFID gate and COBOT-assisted handling.

A live Excel dashboard layer was used to record quality and production KPIs without changing the routing logic of the simulation.

Key findings

CNC machining was identified as the governing constraint. Under the model assumptions, availability improvements produced a greater output increase than further reductions in downstream cycle times.

The project demonstrated that targeted Industry 4.0 deployment should focus on fault detection, maintenance response and availability recovery at the governing resource rather than applying digital monitoring uniformly across the line.

Industrial project · Caterpillar Inc.

Capital expenditure project · March 2025 – July 2025

Redesign of an axle value stream to support the transition from two shifts to one shift while retaining production throughput.

The work included planning and de-risking the relocation of an IPV vision-system station, production-station setup, tool configurations and the installation of large-screen production reporting linked to the manufacturing execution system.

IPV Vision-System Upgrades and Software Beta Test

Industrial project · Caterpillar Inc.

July 2024 – July 2025

Production support for newly introduced image-inference software used by site vision systems. The work involved investigating production issues, supporting software patches and developing a standard configuration and installation package for site-wide upgrades.

The project combined manufacturing support with IT networking and cybersecurity awareness. Internal configuration details are intentionally excluded from the public portfolio.
