# Adam Munn Engineering Portfolio Starter

## Open the site

1. Double-click `index.html`.
2. The site opens directly in your browser.
3. Use Notepad++ to edit the HTML files and `assets/styles.css`.
4. Refresh the browser after saving a change.

## Add files

- Put public or reviewed PDFs in `documents/`.
- Put images in `images/`.
- Do not copy confidential source files into this folder.

## Recommended first edits

1. Open `cad.html` and replace the throttle-project placeholders.
2. Open `dissertation.html` and add your dissertation title.
3. Open `about.html` and add a short profile.
4. Open `index.html` and refine the opening paragraph.

## Later

When the content and appearance are approved, the site can be moved into GitHub and deployed publicly. Node.js and Astro can be revisited at that point if the additional structure is useful.
